# 竹影小手机（SillyTavern 扩展）

在酒馆里加一个悬浮的小手机：

- **微信**：和当前角色、任意 NPC 聊天，可建群聊；加联系人；改备注 / 关系 / 头像；设置自己的网名和头像。
- **查角色的手机**：微信、钱包、备忘录、相册、通话记录（内容由 AI 按角色设定和剧情现编并保存）。可选成人向软件「撸了吗」「♥视频」，**默认关闭**，在设置里开启。
- **与正文互通**：小手机里的角色知道正文发生过的事；正文也知道小手机里发生的事；正文里写到“发消息”时，生成完会自动出现在小手机里（可关）。
- **朋友圈**：微信里可看/发/点赞/评论，可「生成朋友圈」「生成评论」；查手机→微信里以角色身份操作（帮发，角色知道，其他人通常不知道）。设置里可单独选择是否连通正文。
- **美化**：原色 / 黑白 / 黑白·夜，可导入主题（.json / .css）；「快速自定义」可改气泡颜色/圆角、字体、壁纸、桌面图标，并一键导出为 CSS 分享。
- **角色图册**：像集邮册的相册，分「生活 / 私密」（私密受R18开关控制）。每个人可添加自己的图（上传或填链接），图存在自己浏览器本地（IndexedDB），不进聊天、不影响别人。设置里可关闭，关闭后桌面不显示图标。作者也可在 `index.js` 顶部填 `ALBUM_URL` 提供只读的预置图（格式见 `album-sample.json`）。
- **锁屏**：设置里可开启，数字密码或轻触圆圈解锁。
- **悬浮窗**：可拖动；标题栏 ▭ 可缩成小窗（手机端也能悬浮）；底部 ◁ ○ 返回键；点空白处收起（不会打断生成）。

## 数据与隔离
数据存在**当前聊天**的元数据里：不同卡、不同聊天、不同身份(persona)各是一部独立的手机，互不相通，换聊天就换一部。
API 地址 / 密钥 / 外观存在浏览器本地（localStorage），不会随聊天导出。

## 安装
酒馆 → 扩展（积木图标）→ 安装扩展 → 填入本仓库地址。
手动安装：把 `ST-Phone` 文件夹放进 `SillyTavern/public/scripts/extensions/third-party/`（或用户目录下的 `data/<用户>/extensions/`），刷新页面。

## 使用
页面出现悬浮按钮「机」，点击打开。设置里可填 OpenAI 兼容接口（地址留空则使用酒馆当前连接）。
想关闭：在酒馆扩展管理里禁用本扩展，或在小手机设置里关掉悬浮按钮 / 同步开关。

## 说明
- 开启“正文知晓”类开关时，每次生成会额外发送一小段提示（几十到几百字），不需要可全部关闭。
- 读取正文时默认忽略思考块、代码块；其他自定义标签可在设置「过滤标签」里添加。
- 暂不支持群聊（按当前单角色聊天设计）。
